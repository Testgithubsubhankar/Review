What it does

One search box, one clean table.

No manual copy-pasting through review pages — the app does the search, the click-through, and the parsing for you.

01 · SEARCH

Search-driven lookup

Type a product name and the app builds the Flipkart search URL, opens the top listing, and loads its product page — no links to hunt down.

02 · PARSE

Structured extraction

BeautifulSoup walks the review blocks on the page and normalizes each one into reviewer name, star rating, headline, and comment.

03 · EXPORT

Table + CSV, together

Results render instantly as an on-page table, and the same run writes a matching CSV file named after your search term.

Under the hood

Five steps, one Flask route.

Everything happens inside a single POST request to /review.

Build search URL

The submitted product name is cleaned and appended to Flipkart's search endpoint.

Load search results

urlopen fetches the search page and BeautifulSoup locates the first real product listing.

Open product page

The listing's link is resolved to a full URL and requested with requests.

Extract review blocks

Each review card is parsed for name, rating, headline, and comment text, with fallbacks for missing fields.

Render + write CSV

Results populate results.html and are simultaneously written to a CSV file.

Honest notes

Where this needs care before production use.

Worth knowing before pointing this at a client's live catalog.

Markup-dependent selectors

The parser targets Flipkart's current CSS class names. If Flipkart changes its markup, the selectors need updating to match.

First match only

The scraper opens the first product in the search results — it doesn't yet let a user pick between multiple matches.

Single page of reviews

It reads whatever reviews load on the initial product page; there's no pagination or "load more" handling yet.

Terms of service

Scraping a third-party site is subject to that site's terms. For production or commercial use, an official reviews API is the safer route.
